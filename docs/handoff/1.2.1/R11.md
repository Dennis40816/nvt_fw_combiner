1. **R11-01: 4 retain, 3 simplify, 1 delete candidate.** The only item with static evidence of no callers is the `AbMergeByIc` accessor; this must not expand into deletion of the entire registry. 4. Two onboarding documentation discrepancies were found: the guide omits the AB primary FWConfig exception; the detailed NT51950 row in the supported matrix still calls all AB routes Supported. Current ADR/exact-route policy remains authoritative for both; these are inputs for documentation corrections, without proposed firmware behavior changes (section 6).
