## 1. 結論

**應恢復 ADR 0044 的 General stamp-only 契約，並沿既有 input identity owner 修正；不能只讓共用 inspector 回傳空 bytes。** ADR 明定 authoring 不保存完整 BIN，Preview／Build 必須重開並核對完整長度及 SHA-256；現行 General 卻將完整 bytes 複製進 inspection、slot、execution reader，兩個 lifecycle tests 也要求來源改變後成功使用舊 bytes。這是已證實的契約／code／test drift，承接 R09-01 C-01，不另列第二個 ownership 工作項。證據：`docs/adr/0044-content-authoritative-general-selected-files.md:19`、`:82`；`src/NvtFwCombiner.Application/Authoring/GeneralSelectedFileInspection.cs:35`；`src/NvtFwCombiner.Application/Authoring/AuthoringSessionState.SelectedFileInspection.cs:451`；`src/NvtFwCombiner.Application/Composition/AcceptedSessionCompositionExecution.cs:244`；`tests/NvtFwCombiner.Bootstrap.Tests/GeneralSelectedFileExecutionLifecycleTests.cs:59`、`:221`；`docs/handoff/1.2.1/R09-01.md:83`。

**保留 bytes consumer，不等於保留 General authoring 整檔 retention。** Standard／AB／CtrlRAM 的 accepted-session bytes 有 ADR 0048／0049 明文依據，兩份 ADR 也明示未取代 General reopen 契約。General Replace Base 確實需要 bytes 做 firmware metadata／postbuild 規劃及 reference 初始化；建議改為 inspection 暫態讀取及每 run immutable artifact，authoring 只留 identity 與 typed facts。fixed workflows 的 bytes 契約本項保留。證據：`docs/adr/0048-headless-slot-readiness-and-compilation-identity.md:79`、`:86`；`docs/adr/0049-unified-preload-lifecycle.md:315`、`:322`；`src/NvtFwCombiner.Infrastructure/Composition/BuiltInGeneralAuthoringPlanner.cs:227`；`src/NvtFwCombiner.Domain/Composition/CompositionEngine.Inputs.cs:179`。

**Run-time 讀取應延伸既有 port／adapter，snapshot 機制尚待決策（2026-10-04 更新：已由決策 305 選定 host-owned staging copy，下方「staging copy 與持有 share-deny handle 都是候選」的敘述僅為當時的狀態）。** `IArtifactReader` 已是 Application artifact-read port；`FileArtifactReader` 提供受 root 限制的實體檔讀取，`OverlayArtifactReader` 提供 virtual artifacts 與 fallback 組合。General 現行 execution 使用 `AcceptedArtifactReader`，沒有重新讀取磁碟。`1.2.4` 應沿既有 seam 補足 bounded storage 與 immutable lifetime，保留 `CompositionRunService` 的 stamp admission authority；完整 staging copy 或持有 share-deny handle 的取捨須以量測與生命週期證據決定。證據：`src/NvtFwCombiner.Application/Ports/IArtifactReader.cs:4`；`src/NvtFwCombiner.Infrastructure/Files/FileArtifactReader.cs:23`；`src/NvtFwCombiner.Infrastructure/Files/OverlayArtifactReader.cs:32`；`src/NvtFwCombiner.Application/Composition/AcceptedSessionCompositionExecution.cs:528`、`:574`；`src/NvtFwCombiner.Application/Composition/CompositionRunService.Inputs.cs:296`。

本輪交付是契約方向、consumer map 與驗收計畫；**不是實作完成或發布證據**。若以「固定來源已符合 General stamp-only」評判，scoped Polytail verdict 為 **FAIL**；主要 finding 是上述 P1 契約漂移。這與交叉審查對原稿提出的 2 P2、3 P3 是不同評估對象。實作排 `1.2.4`；本修訂已處理五項審查 finding，仍待 owner 採納，不宣稱已獲修訂後複審確認。固定來源 board 尚未承接 R02-01／O05，採納後需由 commander 同步。證據：`docs/architecture/nfc_roadmap.md:410`、`:413`；`docs/handoff/1.1.14/1.2.x-allocation.md:79`、`:164`；`docs/handoff/1.2.1/README.md:10`、`:26`；`docs/handoff/1.2.x.md:3`、`:41`。
