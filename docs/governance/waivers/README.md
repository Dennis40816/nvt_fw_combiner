# Historical evidence

This directory is historical and frozen in place by ADR 0080 item 2 at G1-B.
Its files are evidence only, pinned together with this README. Read the
[Historical record contract](../capability-reuse-record.md) to interpret the
recorded lifecycle; it grants no current admission or completion authority.

Owner approvals under [ADR 0080 item 7](../../adr/0080-governance-reset.md#review-and-approval)
replace external attestations. New waivers are pull request statements under
[the execution workflow](../development-execution-workflow.md), as required by
ADR 0080 item 15. Existing evidence remains unchanged.
