## Confirmed deviations corrected during this audit

1. Root `SPEC.md` still described AB TPA/TPB as declared-prefix inputs whose
   extra bytes always warned. It now distinguishes exact DP AB from generic TP
   source views and optional outer-length diagnostics.
2. The terminology register said a file in an Initial Code/DP role could never
   classify as FlashCode. It now distinguishes role from the resolved
   Application classification.
3. Shared slot guidance treated every ignored tail as a warning. It now makes
   warning status profile-declared while retaining tail detail in reports.
4. The Standard Merge flowchart and ADR 0011 verification text still implied
   the retired DP-size warning for current built-ins. They now record the ADR
   0045 supersession.
5. AB topology/FWConfig validation and execution-snapshot reporting accepted
   only the old declared-prefix type. They now consume the canonical compiled
   inspection result.
6. The compiler allowed a declared-prefix snapshot, but not an equivalent
   source-view snapshot, to initialize an engine-owned work buffer. The generic
   checked snapshot rule now covers both without weakening exact output
   Reference initialization.
7. Architecture caller-set and source-file-size assertions still reflected the
   pre-migration ownership shape. The caller set now records the retired
   Bootstrap classifier dependency, and compiler/test slices remain below the
   repository threshold.

No separate correction ticket was opened. Every confirmed implementation
deviation was unmerged work inside #259 or an explicitly owned #259 migration
surface. Creating another ticket would duplicate authority. #230 remains the
only owner for deleting compatibility types and compiler branches after
zero-caller evidence.
