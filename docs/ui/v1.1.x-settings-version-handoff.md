### Layout and behavior

- Preserve the Settings modal, 318 px navigation rail, header, current-version
  anchors and existing font/theme/button roles.
- Compact the verified-update banner to 64 px minimum height and its existing
  primary Install update action to 150×40 px minimum. Keep explicit consent.
- Give Update source the same width as the version table. Its leading 40 px
  segment retains typed status/progress with a small icon, without a tinted
  block or internal divider. The editable path remains followed by the pencil;
  its tooltip exposes the complete draft/committed path.
- Browse appears only while editing. The existing draft transaction still owns
  Browse/Confirm/Cancel. Cancel restores the committed path without loading;
  Confirm alone submits a new source. Check now does not commit the draft.
- Move secondary Check now to the available-versions heading's right edge.
  Place inventory counts below the table. Retain text statuses and the offline
  explanation; Connected is not a package-verification claim.
- Keep separate stable action/delete/disclosure columns and no vertical grid
  lines. Per-version notes use existing admitted Catalog `releaseNotes`
  verbatim as plain text. No catalog notes means no disclosure; no second file
  or network lookup. Empty and whitespace-only notes remain absent.
- Use the shared `inlineDisclosure` ToggleButton. Space/Enter operates only
  notes, never install/switch/delete. Its accessible name combines the existing
  localized View release notes label with the version. Each projected row owns
  transient expansion state, initially collapsed; refreshed/rebound rows do
  not inherit another version's expansion. Long notes wrap in the existing
  outer page scroll owner, without a nested scrollbar.
- Retain rounded shared buttons and backgroundless checked arrows even where
  the generated preview slightly changed their radii or icon scale. The actual
  connected icon is 18 px, source field is 54 px including its existing 2 px
  border, row header is 58 px, and chevrons use the existing small path motif.
  These are existing-control adaptations, not new global button styles.

The compact Traditional Chinese render exposed the old font-dependent `ⓘ`
as missing-glyph bars. The two local information indicators now reuse the
existing Settings navigation information-icon geometry through one local
resource. Their adjacent localized text remains the meaning/accessible owner.
