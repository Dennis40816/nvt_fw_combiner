## Link-audit evidence

The pre-deletion evidence scan and the post-deletion reference check are
reproducible from the frozen basis plus planning worktree. For each approved
path, run `git grep -a -l -F -- "$path"` for binary-safe unique tracked files
containing the exact path. The base control-file exclusion list is exactly:

1. `docs/architecture/v1.1.2-repository-document-convergence-manifest.md`
2. `tests/NvtFwCombiner.Architecture.Tests/RepositoryBoundaryTests.Roadmap.cs`

Normalize the returned file paths, then classify each unique path against that
list. The six non-governance removals have unique tracked files `2`, control
files `2`, and non-control inbound links/callers `0`. The governed D2 checklist
path, `docs/governance/owner-verification-inputs-0.8-to-0.9.md`, has one
additional control: `docs/governance/change-records/DOCS-112-RETENTION-CLEANUP-01.json`.
Its result is unique tracked files `3`, control files `3`, and non-control
inbound links/callers `0`. The full path is the authoritative caller identity.
The pre-deletion basename, title, and directory/stem scans were diagnostics
only—generic `README.md` matches are not callers—and did not change approval.

The unique-file result is `2 / 2 / 0` for each non-governance removal and
`3 / 3 / 0` for D2. The three test README basename scans each found 24 generic
`README.md` paths; their title/stem scans are likewise non-unique diagnostics,
not callers. The four non-README candidate basename/stem scans found only the
candidate/control context; title screens found their source title plus no
non-control caller. These diagnostics do not change any disposition.

```powershell
$baseControls = @(
  'docs/architecture/v1.1.2-repository-document-convergence-manifest.md',
  'tests/NvtFwCombiner.Architecture.Tests/RepositoryBoundaryTests.Roadmap.cs'
)
$controlsByPath = @{
  'docs/governance/owner-verification-inputs-0.8-to-0.9.md' = @(
    $baseControls + 'docs/governance/change-records/DOCS-112-RETENTION-CLEANUP-01.json'
  )
}
$approvedPaths = @(
  'docs/architecture/general-replace-binary-patch-proposal.md',
  'docs/governance/owner-verification-inputs-0.8-to-0.9.md',
  'tests/NvtFwCombiner.Application.Tests/README.md',
  'tests/NvtFwCombiner.ProfileContract.Tests/README.md',
  'tests/NvtFwCombiner.UiSmoke.Tests/README.md',
  'docs/ui/page-review-2026-07-04.md',
  'docs/references/tutorial/NVT_FW_Combiner_0.7.3_Tutorial.pptx'
)
foreach ($path in $approvedPaths) {
  $expectedControls = if ($controlsByPath.ContainsKey($path)) {
    $controlsByPath[$path]
  } else {
    $baseControls
  }
  $files = @(git grep -a -l -F -- $path |
    ForEach-Object { $_.Replace('\', '/') } | Sort-Object -Unique)
  $nonControl = $files | Where-Object {
    $_ -notin $expectedControls
  }
  [pscustomobject]@{
    Path = $path; UniqueFiles = $files.Count; ControlFiles = $files.Count - $nonControl.Count
    NonControl = $nonControl.Count
  }
}
```
